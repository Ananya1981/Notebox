# 📦 NoteBox — Stationery Subscription Platform (Landing Page)

A clean, minimalist single-page landing layout with a background stationery video and sign-in flow.

## 🎨 Theme
- **Background:** White
- **Typography:** Black
- **Buttons / Accents:** Royal Purple (`#9333ea` / `#7e22ce`)

## 📁 Source Structure
```
src/
├── components/
│   └── LoginPage.jsx   # Clean Login & Sign-in card view
├── App.jsx             # Single-page hero with background video & controls
├── index.css           # Minimal Tailwind styling & typography
└── main.jsx            # Entry point
```

## 🚀 Running Locally
```bash
npm install
npm run dev
```
